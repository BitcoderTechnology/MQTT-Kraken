Built for people who already speak MQTT.

Inspired by MQTT Dash — with the piece that was missing: live widgets you can tap from the launcher.

Home-screen widgets

Single tiles or resizable grids. Tap a switch or button without opening the app.

Live last-value cache

A foreground connection keeps topics fresh so widgets show the latest payload, not a stale snapshot.

MQTT Dash import

Bring your existing JSON export, including JavaScript hooks, and keep building from there.

Switches, gauges, more

Text, switch, button, gauge, and image tiles — enough for EV charging, heating, lights, and cameras.

JavaScript hooks

jsOnReceive, jsOnDisplay, and jsOnTap run locally via Rhino — same MQTT Dash style.

Your broker, nobody else’s

No Kraken cloud. Optional TLS. Credentials stay on the phone and never go to a Bitcoder server.

No cloud account

Traffic goes to your broker. That’s it.

MQTT Kraken does not run a backend, analytics, crash reporting, or ads. Configuration stays on the device. You can start and stop the connection in Settings.
